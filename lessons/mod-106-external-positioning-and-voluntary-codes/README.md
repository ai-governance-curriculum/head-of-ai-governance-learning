# mod-106-external-positioning-and-voluntary-codes: External Positioning, Voluntary Codes, and Standards-Body Leadership

> Scaffolded by `aicg org execute-plan`. Lecture chapters and exercise content are authored on subsequent autonomous cycles.

**Estimated effort:** 14 hours

## Learning objectives

- Design the internal decision process for signing on to a voluntary code — EU AI Office GPAI Code of Practice, G7 Hiroshima Process Code of Conduct, White House Voluntary AI Commitments where applicable, Frontier Model Forum charter where frontier-lab scope applies, Partnership on AI membership, MLCommons AI Safety Working Group participation, US AISI Consortium (AISIC) membership — with the CEO / GC / CRO / CFO sign-off flow explicit
- Design the standards-body participation posture at leadership scope — ISO/IEC JTC 1/SC 42, CEN-CENELEC JTC 21, IEEE 7000-series, NIST public workshops (AI RMF, AISI publications, AISIC working groups), OECD.AI Expert Group; whether the head personally chairs a working group or the senior architect represents in technical body sessions
- Design the public trust posture — public speaking, position papers, industry-body board seats, media strategy in coordination with Communications (this role owns the AI-governance substance; Communications owns the delivery)
- Design the enterprise's RFI / RFP response posture — regulator RFIs (CPPA, EU AI Office, NIST, US AISI), industry-body RFIs (Frontier Model Forum, Partnership on AI, MLCommons), academic RFIs — with the internal drafting cycle
- Rehearse the difficult external decision — declining to sign a voluntary code and defending the position; withdrawing from a code and defending the position; publicly disagreeing with a regulator's methodology and framing the disagreement without burning the relationship
- Draw shape lessons from frontier-lab external positioning (Anthropic RSP publication cadence, OpenAI Preparedness Framework updates, Google DeepMind FSF publication cadence) — the enterprise equivalent is emerging
